# ADR-0009: обновлять Codex Desktop через локальный IPC

- Статус: заменено ADR-0010 для локальных задач
- Дата: 2026-07-27

## Контекст

ChatGPT Desktop и отдельный `codex app-server` используют общую сохранённую
историю, однако открытый renderer не перечитывает изменения внешнего turn
автоматически. Полный перезапуск приложения показывает prompt и result,
созданные worker.

На Windows установленное приложение создаёт локальный named pipe
`\\.\pipe\codex-ipc`. Это внутренний маршрутизатор событий Desktop. Протокол
использует JSON-фреймы с четырёхбайтовой little-endian длиной.

Read-only исследование установленного bundle и живой probe подтвердили:

- клиент регистрируется запросом `initialize`, версия `0`;
- событие `query-cache-invalidate`, версия `0`, принимает `queryKey`;
- `["tasks"]` инвалидирует облачные списки `/wham/tasks`;
- `["task", "<taskId>"]` инвалидирует данные облачной задачи;
- broadcast не запускает turn и не изменяет сохранённую историю.

Локальный Codex-thread хранится в AppServerManager/Jotai. Его sidebar использует
идентификатор `local:<threadId>`, а открытая переписка получает состояние через
`thread/read` и runtime events. TanStack keys `["tasks"]` и `["task", ...]`
не обновляют этот контур.

## Решение

Windows-worker версии `0.1.9` после запуска, продолжения и завершения turn:

1. открывает `codex://threads/<threadId>`;
2. даёт Desktop короткое окно на обработку deep link;
3. подключается к `\\.\pipe\codex-ipc`;
4. отправляет один broadcast для `["tasks"]`;
5. отправляет один broadcast для `["task", "<threadId>"]`;
6. закрывает соединение;
7. повторяет уведомление после `turn/completed`.

Подключение имеет короткий timeout. Отсутствующий Desktop или недоступный pipe
не останавливают выполнение worker: deep link и headless turn сохраняют
текущее поведение. Ошибка IPC записывается в stderr worker для диагностики.

## Границы

Живой Windows E2E подтвердил framing и доставку broadcast. Открытая локальная
переписка не изменилась. Продолжение локальных задач переведено на
Desktop follower в ADR-0010. Для macOS нужен отдельный эксперимент с
фактическим локальным endpoint.

Во время live-диагностики также обнаружен восстановленный turn, который
сохранял `busy` и не реагировал на `turn/steer`. Отмена и lease активной работы
оформляются отдельной задачей; обновление renderer не должно зависеть от
завершения turn.
