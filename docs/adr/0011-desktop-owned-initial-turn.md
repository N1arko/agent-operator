# ADR-0011: передавать первый turn новой задачи владельцу Desktop

- Статус: принято, macOS и Windows E2E подтверждены
- Дата: 2026-07-28

## Контекст

`agent_start` создавал задачу и первый turn отдельным `codex app-server`.
Задача появлялась в списке ChatGPT/Codex Desktop, однако открытая карточка могла
оставаться пустой до перезапуска приложения. Для продолжения существующей
задачи ADR-0010 уже использует локальную команду Desktop
`thread-follower-start-turn`.

Одинаковый IPC-handler зарегистрирован в Desktop на Windows и macOS. На macOS
приложение принимает подключения через
`$CODEX_HOME/ipc/ipc.sock`.

## Решение

Новый проектный запуск выполняется в два этапа:

1. worker создаёт пустую постоянную задачу через публичный
   `thread/start`;
2. задаёт заголовок через `thread/name/set`;
3. открывает `codex://threads/<threadId>`;
4. передаёт первый prompt владельцу Desktop через
   `thread-follower-start-turn`;
5. отдельный read-only app-server ждёт сохранённый `completed` и извлекает
   финальный ответ для coordinator.

Если Desktop отклонил команду до принятия turn, worker продолжает задачу через
app-server. После принятия Desktop-команды второй запуск не создаётся.

Worker выбирает локальный endpoint по платформе:

- macOS: `$CODEX_HOME/ipc/ipc.sock`;
- Windows: `\\.\pipe\codex-ipc`.

## Проверка

Mac-worker `0.1.15` создал задачу
`019fa635-adea-72d0-9945-d2196c6b6260`. Открытый Desktop без перезапуска
показал:

- первый пользовательский prompt;
- завершённый turn `019fa635-dbb5-7ef3-b7ab-8138b5d65719`;
- финальный ответ `MAC_DESKTOP_START_015_OK`.

Coordinator получил один `completed` result, связанный с той же задачей.

Windows-worker `0.1.15` затем создал задачу
`019fa656-f63a-7bb0-98f5-bae1b7691cfd` и вернул точный result
`WINDOWS_DESKTOP_START_015_OK` за `16,158 ms`. Пользователь подтвердил, что
карточка сразу показывает исходный prompt и финальный ответ.

## Последствия

Новая удалённая задача сразу отображает prompt, прогресс и результат в
интерфейсе принимающего компьютера. Заголовок и проектный `cwd` сохраняются до
начала выполнения. Когда Desktop закрыт, остаётся штатный headless fallback.
