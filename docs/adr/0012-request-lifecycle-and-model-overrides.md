# ADR-0012: Lease, cancellation and model overrides

Дата: 2026-07-28
Статус: принято

## Контекст

Исторические сообщения со статусом `delivered` могли занимать ограниченный
backlog после остановки worker или незавершённого Desktop-turn. Удалённый
запуск наследовал настройки модели принимающего Codex без явного выбора.

## Решение

Каждый исполняемый запрос получает `leaseExpiresAt`. Стандартный lease
составляет два часа и задаётся coordinator через `AOP_REQUEST_LEASE_MS`.
Coordinator переводит просроченный запрос в `failed`, создаёт один итоговый
result и освобождает backlog. Worker использует тот же срок для остановки
локального turn.

MCP-инструмент `agent_cancel` принимает точный ID исходного запроса.
Coordinator фиксирует `cancelled`, публикует result и отправляет worker
служебное сообщение `cancel`. Worker удаляет запрос из локальной очереди или
вызывает Desktop follower `thread-follower-interrupt-turn` для активного turn.

`agent_models` запрашивает локальный `model/list` принимающего Codex.
`agent_start`, `agent_send` и `agent_thread_send` принимают опциональные
`model` и `reasoningEffort`. Worker проверяет выбор по локальному каталогу и
передаёт параметры в Desktop-owned `turnStartParams`. Отсутствующие параметры
сохраняют настройки принимающей задачи.

## Последствия

- зависшие запросы освобождают очередь в конечный срок;
- отмена имеет отдельный результат `cancelled`;
- явный выбор модели проверяется на компьютере, который выполняет работу;
- coordinator хранит только выбранные идентификаторы и срок lease;
- старые активные записи получают lease при миграции SQLite.
