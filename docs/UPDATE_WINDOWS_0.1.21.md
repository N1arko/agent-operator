# Обновление Windows-worker до 0.1.21

## Цель

Добавить atomic inbox claim, чтобы несколько ошибочно запущенных worker одной
identity не могли одновременно получить один request.

## Проверки

- package SHA-256 совпадает с опубликованным значением;
- coordinator health показывает `0.1.21`;
- Scheduled Task запускает один worker из каталога `0.1.21`;
- heartbeat стабильно показывает только `0.1.21`;
- два конкурентных inbox poll получают request суммарно один раз;
- потерянный HTTP-ответ разрешает повторный claim после короткого delivery
  lease;
- один request создаёт один Desktop turn и один result;
- progress activity ограничена по частоте;
- `diagnose.ps1` и `npm audit --omit=dev` завершаются успешно.

## Порядок

1. Скачать onboarding package и проверить SHA-256.
2. Установить каталог `0.1.21` с действующей конфигурацией.
3. Выполнить diagnose, audit и установить bundled integration.
4. Обновить основной Scheduled Task на `0.1.21`.
5. Через одноразовую отложенную задачу завершить все подтверждённые процессы
   Agent Operator 0.1.18–0.1.20 и запустить один основной worker.
6. Проверить стабильный heartbeat и живой двусторонний E2E.

Предыдущие каталоги сохраняются для отката.
