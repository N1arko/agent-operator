# Code of Conduct

Agent Operator welcomes respectful technical collaboration.

## Expected behavior

- Be clear, patient and specific.
- Critique ideas and implementations without attacking people.
- Respect privacy, credentials and unpublished security information.
- Give contributors credit and make room for different experience levels.
- Keep issue and review discussions relevant to the project.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate disclosure of private
information, sustained disruption and bad-faith security reports are not
accepted in project spaces.

## Enforcement

Report conduct issues privately through
[GitHub private vulnerability reporting](https://github.com/N1arko/agent-operator/security/advisories/new)
and mark the report as a conduct concern. Maintainers may edit or remove
content, close discussions, reject contributions or restrict participation.
Reports will be handled with appropriate confidentiality.

This policy applies to repository discussions, reviews, project chat and public
events where someone represents Agent Operator.
