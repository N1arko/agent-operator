# Agent Operator {#root}

## Простыми словами {#plain-language}

Agent Operator связывает независимые экземпляры Codex на разных компьютерах и
аккаунтах. Один агент видит доступность другого, выбирает его локальный проект
или задачу, отправляет работу, наблюдает состояние и получает итог.

## Назначение {#goal}

Система предоставляет лёгкий mailbox и presence-контур. Выполнение и локальный
контекст остаются на компьютере принимающего агента.

## Продуктовые границы {#scope}

В текущий продукт входят:

- обнаружение зарегистрированных агентов и их безопасного статуса;
- выбор опубликованного проекта или существующей задачи;
- новый и связанный turn, очередь, ожидание, lease и отмена;
- отображение удалённого выполнения в Codex Desktop;
- передача committed Git-файлов и небольших временных вложений;
- работа macOS и Windows через постоянно доступный локальный worker.

Coordinator не получает полный список локальных чатов, абсолютные пути
проектов и содержимое рабочих каталогов. Крупное файловое хранилище,
многопользовательские ACL, web-интерфейс и несколько активных turn остаются за
границей текущего канона.

## Критерий продукта {#success}

Два Codex с разными аккаунтами и компьютерами должны выполнить двусторонний
сценарий через обычный чат: создать или продолжить задачу, показать prompt и
результат в Desktop принимающей стороны, вернуть один итог отправителю и
освободить worker.
