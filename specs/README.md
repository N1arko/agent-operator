# Спецификации Agent Operator

Каталог `specs/` — канонический слой проекта. При расхождении со старым
описанием в `docs/` действует актуальная спецификация. ADR сохраняют причины
решений, E2E-отчёты подтверждают фактическое поведение релизов.

## Вход в работу

1. Выполнить [`protocols/BOOT.md`](protocols/BOOT.md).
2. Найти управляющую спеку через [`common/structure.md`](common/structure.md).
3. Сверить состояние work item в [`BOARD.md`](BOARD.md).
4. Читать [`WAL.md`](WAL.md) только для активной карточки.

## Типы документов

- `PROP` — долговечные инварианты и границы.
- `FEAT` — наблюдаемая продуктовая возможность.
- `INFRA` — runtime, deployment, storage и восстановление.
- `BOARD` — зарегистрированная работа.
- `WAL` — краткий handoff активной работы.
- `TECHDEBT` — осознанно оставленные компромиссы.

Спека адресуется полным URI вида
`spec://modules/worker/FEAT-005-desktop-visible-delivery#scenarios`.
