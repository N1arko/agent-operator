# Протокол WAL

WAL хранит только контекст активной работы, который нужен следующей сессии:

- ID и полный адрес спеки;
- owner и дата старта;
- достигнутый результат;
- следующий конкретный шаг;
- блокеры и важные локальные состояния.

WAL не дублирует историю коммитов, BOARD, changelog или подробный дневник.
После завершения work item активная секция удаляется.
