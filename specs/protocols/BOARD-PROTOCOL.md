# Протокол BOARD

- В BOARD попадает только работа с существующей полной `spec://`-ссылкой.
- Колонки: `Backlog`, `In Progress`, `Blocked`, `Done`.
- `In Progress` содержит owner и дату старта.
- Активная работа с handoff имеет секцию WAL с тем же owner.
- Блокировка содержит причину и конкретное условие продолжения.
- `Done` содержит owner, дату и подтверждённый результат.
- Идеи без готовой спеки хранятся в ROADMAP.
- Исправление уже описанного поведения получает ID `FIX-NNN` и ссылается на
  точный якорь существующей FEAT или INFRA. Отдельная спека для такого
  исправления не создаётся.
